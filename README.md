# Soundpad Track Hub

![Windows 10/11](https://img.shields.io/badge/Windows-10%20%7C%2011-0078D6)
![.NET 8](https://img.shields.io/badge/.NET-8-512BD4)
![License: MIT](https://img.shields.io/badge/license-MIT-green)

Бесплатная программа с **открытым исходным кодом**: компактная панель-помощник для [Soundpad](https://leppsoft.com/soundpad/) под Windows.
Встаёт рядом с окном Soundpad, открывает сайт **ru.hitmoz.org во встроенном браузере Microsoft WebView2**
и аккуратно принимает MP3, которые вы скачиваете **штатной кнопкой на самом сайте**.
Скачанный трек сразу попадает в отдельную категорию Soundpad — не нужно искать файл и перетаскивать его вручную.

## Что это за программа

Soundpad — программа, которая проигрывает звуки и музыку в микрофон (Discord, игры, созвоны).
Обычно, чтобы добавить туда новый трек, нужно найти его в браузере, скачать, найти файл в папке и перетащить в Soundpad.
**Soundpad Track Hub делает всё это в одном окне:** ищете трек → нажимаете «скачать» → трек уже в Soundpad.
Ещё в нём можно переключать громкость Soundpad («Нормально», «Громко», «Супер громко») в один клик.

## Открытый исходный код

Весь код программы лежит в этом репозитории, и его может посмотреть любой человек.
Это значит:

- **можно проверить, что программа безопасна** — в ней нет вирусов, майнеров, рекламы и сбора данных;
  она не внедряется в Soundpad и не меняет его файлы;
- **можно собрать программу самому** из исходников (см. раздел «Сборка»), а не доверять готовому exe;
- **можно предлагать улучшения** — через Issues и Pull Requests;
- код распространяется по лицензии [MIT](LICENSE): его можно свободно использовать, изменять и распространять,
  сохраняя уведомление об авторских правах.

> Программа не связана с Leppsoft (разработчиком Soundpad) и с сайтом Hitmoz. «Soundpad» указан только для обозначения совместимости.

## Скачать и установить

1. Откройте раздел **[Releases](../../releases)** и скачайте `SoundpadTrackHub-Setup-<версия>.exe`.
2. Запустите установщик, прочитайте и примите [пользовательское соглашение](installer/AGREEMENT.ru.txt).
3. Установщик поставит программу (права администратора не нужны), создаст ярлык на рабочем столе
   и включит автозапуск — чтобы Track Hub сам появлялся каждый раз, когда вы открываете Soundpad.

Windows SmartScreen может предупредить «Неизвестный издатель», потому что у бесплатного проекта нет платной цифровой подписи.
Нажмите «Подробнее» → «Выполнить в любом случае». Если сомневаетесь — соберите программу сами из исходного кода.

> **Важно: Track Hub не работает с Hitmoz через API.** Сайт отвечает HTTP 403 на автоматические
> запросы (`HttpClient`, `curl`), и обходить это нельзя. Поэтому вы сами ищете трек на странице
> сайта и сами нажимаете на ней кнопку скачивания. Track Hub только перехватывает эту обычную
> браузерную загрузку, проверяет её и спрашивает подтверждение. Демо-треков и mock-данных
> в приложении нет.

## Требования

- Windows 10 1809+ или Windows 11 (x64);
- [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (не нужен при сборке с `-SelfContained`);
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/). В Windows 11 он уже есть. Он нужен «под капотом» для поиска: сам сайт в программе не показывается;
- для сборки — .NET 8 SDK.

## Сборка

```powershell
dotnet build SoundpadTrackHub.sln -c Release
dotnet test  SoundpadTrackHub.sln -c Release
```

Запуск без установки:

```powershell
dotnet run --project src\SoundpadTrackHub -c Release
```

Публикация в папку:

```powershell
dotnet publish src\SoundpadTrackHub\SoundpadTrackHub.csproj -c Release -r win-x64 --self-contained false -o artifacts\publish
```

Сборка установщика (нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php): `winget install JRSoftware.InnoSetup`):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-installer.ps1
```

Результат — `artifacts\installer\SoundpadTrackHub-Setup-<версия>.exe`: один файл, внутри которого сжато упакованы программа
(со встроенным .NET 8), пользовательское соглашение и лицензия. Сценарий установщика — `installer\SoundpadTrackHub.iss`.

## Установка без установщика (для разработчиков)

Установка выполняется для текущего пользователя, права администратора не нужны:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Desktop -Autostart
```

Скрипт:

1. собирает приложение (`dotnet publish`);
2. копирует его в `%LOCALAPPDATA%\Programs\SoundpadTrackHub`, заменяя старую версию Track Hub в этой папке;
3. создаёт ярлык «Soundpad Track Hub» в меню «Пуск» (и на рабочем столе — с `-Desktop`);
4. регистрирует приложение в «Установка и удаление программ» (HKCU);
5. с `-Autostart` включает автозапуск. Его можно включить и позже, в настройках.

Ключ `-SelfContained` собирает версию со встроенным .NET: тогда Runtime на компьютере не нужен.

## Как пользоваться

1. Запустите Soundpad и Track Hub. Панель встанет рядом с Soundpad, статус в заголовке сменится на **«Подключён»**.
2. На вкладке **«Поиск»** напишите название трека или исполнителя.
3. Нажмите **⬇** у нужного трека. Перед первым скачиванием Track Hub покажет **пользовательское соглашение** — без согласия скачивание недоступно.
4. Track Hub проверит загрузку и спросит: *«Скачать этот MP3 с Hitmoz? Проверьте права использования трека.»*
5. После загрузки появится карточка с путём к файлу и подсказкой
   **«Перетащите скачанный файл в список звуков Soundpad»**. Карточку можно перетащить прямо в Soundpad,
   а все скачанные треки доступны на вкладке «Загрузки».

### Статусы Soundpad

| Статус | Значение |
|---|---|
| **Подключён** | процесс `Soundpad.exe` найден, окно отслеживается |
| **Ожидание Soundpad** | Soundpad ещё не запускался в этом сеансе |
| **Soundpad закрыт** | Soundpad был запущен и закрылся. Track Hub скрывается в область уведомлений (если это включено) и появится снова при запуске Soundpad |

Значок 📌 в заголовке включает и выключает прилипание к окну Soundpad.

**Крестик не закрывает программу, а прячет её в область уведомлений** (значок у часов). Так Track Hub
продолжает ждать Soundpad и сам появится при следующем его запуске. Полностью выйти: правый клик по значку → «Выход».
Чтобы Track Hub появлялся с Soundpad и после перезагрузки компьютера, должен быть включён автозапуск
(установщик включает его сам, также он есть в настройках).

### Поиск

Вкладка **«Поиск»** открывается первой. Начните печатать название трека или исполнителя: через ~0,6 с
Track Hub загрузит в скрытом встроенном браузере страницу поиска `ru.hitmoz.org/search?q=…` и покажет найденные
треки списком: название, исполнитель, длительность. Сам сайт в программе не показывается.

- **▶** — послушать. Включается плеер самого сайта (как если бы вы нажали трек на странице), повторное нажатие ставит на паузу;
- **⬇** — скачать. Открывается штатная ссылка скачивания сайта, дальше обычное подтверждение
  *«Скачать этот MP3 с Hitmoz? Проверьте права использования трека.»*;
- Enter — искать сразу, без паузы.

Список читается со страницы, которую загрузил встроенный браузер: атрибут `data-musmeta`, длительность, ссылка скачивания.
Отдельных HTTP-запросов к Hitmoz в обход браузера нет.

### Категория «Soundpad Track Hub» в Soundpad

Каждый скачанный трек (и громкая копия) автоматически добавляется в категорию **«Soundpad Track Hub»** в списке звуков Soundpad.
Если категории нет, Track Hub её создаёт. Работает через **официальный интерфейс удалённого управления Soundpad** —
именованный канал `\\.\pipe\sp_remote_control` (команды `GetCategories`, `DoAddCategory`, `DoAddSound`).
Файлы Soundpad не изменяются, код в Soundpad не внедряется.

- Если Soundpad закрыт, треки добавятся автоматически при следующем запуске Soundpad;
- уже добавленные треки повторно не добавляются (проверяется путь файла в категории);
- кнопка «Добавить все скачанные сейчас» и переключатель находятся в «Настройки → Soundpad и Windows»;
- удалённое управление доступно в полной версии Soundpad (не в демо).

### Замена трека — для бесплатной версии Soundpad

В бесплатной (демо) версии Soundpad нет удалённого управления, поэтому новые треки нельзя добавить автоматически.
Для этого есть вкладка **«Замена»**:

1. Нажмите **«Поменять»** у скачанного трека.
2. Выберите в списке звук Soundpad, который хотите заменить (есть поиск по названию и категории).
3. Подтвердите. Если Soundpad открыт, Track Hub закроет его обычным способом, заменит трек и сразу запустит снова.

Звук остаётся на своём месте: номер, категория и горячая клавиша не меняются, меняется только файл, который он играет.
Старый аудиофайл не удаляется. Перед каждой заменой Track Hub сохраняет копию списка Soundpad
(`%APPDATA%\SoundpadTrackHub\soundpad-backups`, последние 15). Чтобы откатить замену, закройте Soundpad и скопируйте
нужную копию поверх `%APPDATA%\Leppsoft\soundlist.spl`.

### Громкость Soundpad

Переключатель **[Нормально] [Громко] [Громко 2] [Супер громко]** на вкладке «Загрузки» и в настройках меняет
настройку Soundpad **«Файл → Настройки → Аудио → Нормализация громкости»**:

| Режим | Громкость голоса | Регулировка | Подстройка громкости |
|---|---|---|---|
| Нормально | 80 дБ | динамическая | — |
| Громко | 95 дБ | динамическая | — |
| Громко 2 | 107 дБ | динамическая | — |
| Супер громко | 107 дБ | **фиксированная** | 30 дБ |

При режиме «Супер громко» показывается подпись *«Усиление может вызвать искажения на некоторых треках»*.
Под переключателем видно, что сейчас стоит в Soundpad.

Как это применяется. Soundpad хранит эти значения в `HKCU\Software\Leppsoft\Soundpad\MainFrame`
(`normalizeTargetDecibel`, `normalizeVolume` (1 — динамическая, 0 — фиксированная), `fixedVolumeAdjustmentDecibel`).
Он читает их только при запуске и записывает при выходе. Поэтому:

- **Soundpad закрыт** — значения записываются сразу и подхватятся при запуске;
- **Soundpad открыт** — Track Hub спрашивает:
  - **«Перезапустить Soundpad»** — Soundpad закрывается обычным способом, значения записываются, Soundpad запускается снова;
  - **«Когда закрою сам»** — режим применится автоматически сразу после закрытия Soundpad;
  - **«Отмена»**.

Другие настройки Soundpad не трогаются. Системная громкость Windows не меняется.

### Предпрослушивание и громкая копия

На вкладке «Загрузки» скачанный файл можно послушать (NAudio, свой ползунок громкости, системная громкость не меняется)
и создать **отдельную громкую копию +6 dB**. После усиления работает look-ahead limiter с потолком −1 dBFS.
Если трек уже слишком громкий для безопасного усиления, Track Hub предупреждает и копию не создаёт.
Оригинал открывается только на чтение и никогда не изменяется.

## Безопасность и права

Правила загрузки:

- **только HTTPS**;
- **только ru.hitmoz.org.** На практике ссылка `https://ru.hitmoz.org/get/music/…mp3` перенаправляет на
  файловый сервер сайта (например, `cdn13.deliciousoranges.com`). Такая загрузка разрешается только если цепочка
  началась с клика по ссылке ru.hitmoz.org на `.mp3` не более 90 секунд назад и итоговый адрес тоже HTTPS.
  Загрузки, которые начались не с ru.hitmoz.org, блокируются;
- **только `.mp3`.** Блокируются `exe, bat, cmd, com, scr, dll, ps1, vbs, js, msi, lnk, reg, hta, jar, zip…`, в том числе
  двойные расширения вроде `track.mp3.exe`;
- проверяется MIME-тип ответа (HTML и исполняемые типы отклоняются), а после загрузки — содержимое файла
  (ID3 или MPEG frame sync; «MZ» и HTML отклоняются);
- внешние переходы и всплывающие окна (реклама) внутри Track Hub блокируются;
- в браузере отключены DevTools (в Release), host-объекты, web-messages и автозаполнение паролей.

Чего Track Hub **не делает**:

- не обходит Cloudflare, CAPTCHA, авторизацию и другие ограничения. Если сайт отвечает **HTTP 403**,
  поиск честно сообщает об ошибке и предлагает попробовать позже;
- не делает HTTP-запросов к Hitmoz в обход браузера и не извлекает аудиофайлы из плеера страницы.
  Вкладка «Поиск» только читает список треков со страницы поиска, открытой в скрытом встроенном браузере;
- не использует DLL injection, не внедряет код в процесс Soundpad, не изменяет и не патчит `Soundpad.exe` и файлы Soundpad.
  Track Hub читает геометрию окна Soundpad (`GetWindowRect`, `SetWinEventHook` в режиме `WINEVENT_OUTOFCONTEXT`),
  добавляет треки через официальный канал удалённого управления и, только по вашему выбору режима громкости,
  меняет три значения нормализации в реестре Soundpad.

Скачивайте только те треки, на которые у вас есть права. Воспроизведение музыки в голосовых чатах, на стримах
и в публичных местах может требовать разрешения правообладателя.

## Удаление

**Настройки → «Удалить приложение»** или «Параметры Windows → Приложения → Soundpad Track Hub → Удалить»
(запускает `SoundpadTrackHub.exe --uninstall`).

1. Вопрос: *«Удалить Soundpad Track Hub? Ваши аудиотреки останутся на компьютере»* — кнопки **«Удалить» / «Отмена»**.
2. Отдельный вопрос: удалить ли базу загрузок и настройки (вместе с журналами и cookies встроенного браузера).
3. Отдельный вопрос: удалить ли скачанные аудиотреки. Удаляются только файлы, которые скачал или создал Track Hub
   (по базе `downloads.json`); остальные файлы в папке не трогаются. По умолчанию треки остаются.
4. Track Hub удаляет запись автозапуска, ярлыки и запись в «Установка и удаление программ», закрывается, и
   PowerShell-скрипт после выхода процесса удаляет `%LOCALAPPDATA%\Programs\SoundpadTrackHub` и временные файлы.
5. Сообщение: *«Soundpad Track Hub успешно удалён. Аудиотреки сохранены»*.

Soundpad, `Soundpad.exe`, его файлы и ключи реестра (`HKCU\Software\Leppsoft`) не удаляются никогда:
любая папка, где лежит `Soundpad.exe`, исключается из удаления.
Если приложение запущено не из папки установки (например, из `bin\Release`), эта папка не удаляется,
и Track Hub прямо об этом сообщает.

## Где что хранится

| Путь | Что |
|---|---|
| `%LOCALAPPDATA%\Programs\SoundpadTrackHub` | программа (после `install.ps1`) |
| `%APPDATA%\SoundpadTrackHub\settings.json` | настройки (папка, режим громкости, прилипание…) |
| `%APPDATA%\SoundpadTrackHub\downloads.json` | база загрузок |
| `%APPDATA%\SoundpadTrackHub\logs` | журналы Serilog (7 дней) |
| `%LOCALAPPDATA%\SoundpadTrackHub\WebView2` | профиль встроенного браузера (cookies сайта) |
| `%TEMP%\SoundpadTrackHub` | временные файлы загрузок (очищаются при запуске и выходе) |
| `Музыка\Soundpad Track Hub` | папка загрузок по умолчанию (меняется в настройках) |

## Ограничения (честно)

- **Hitmoz может быть недоступен.** Если сайт отвечает 403 или требует проверку, Track Hub не обходит её:
  показывается экран ошибки, а сайт можно открыть во внешнем браузере. Файл, скачанный во внешнем браузере,
  Track Hub не перехватывает: его нужно перетащить в Soundpad вручную.
- **Разметка сайта может измениться.** Track Hub не разбирает HTML, поэтому смена дизайна его не ломает.
  Но если сайт перенесёт файлы на ссылки другого вида (не `ru.hitmoz.org/…*.mp3`), политика загрузки их заблокирует —
  тогда её нужно будет обновить (`Services/HitmozPolicy.cs`).
- **Реклама на сайте.** Track Hub блокирует внешние переходы и всплывающие окна, но не вырезает рекламные блоки внутри страницы.
- **Поиск зависит от разметки страницы Hitmoz** (`li.tracks__item`, `data-musmeta`, `a.track__download-btn`).
  Если сайт её поменяет, список станет пустым — тогда нужно обновить программу.
- **Громкость Soundpad применяется только при запуске Soundpad**, поэтому нужен перезапуск (с вашего подтверждения).
  Если в Soundpad открыт какой-то диалог, он может не закрыться — тогда режим применится после ручного закрытия.
  Соответствие `normalizeVolume` = 1 (динамическая) / 0 (фиксированная) определено по вашим настройкам
  (107 дБ + фиксированная 30 дБ ↔ `normalizeVolume=0`); после первого переключения стоит один раз заглянуть в настройки Soundpad.
- **Категория Soundpad** требует полной версии Soundpad с удалённым управлением. Пути Soundpad принимает в ANSI-кодировке
  (на ru-RU — windows-1251); если в пути есть символы вне этой кодировки, трек придётся перетащить вручную.
- **Прилипание** рассчитано на одно главное окно Soundpad. Если Soundpad запущен с правами администратора,
  а Track Hub без них, Windows может не дать отслеживать его окно — тогда панель работает как обычное окно.
- **Усиление**: limiter исключает клиппинг, но на громких мастерингах +12 dB сжимает динамику. Для таких треков
  Track Hub предупреждает и остаётся на нормальной громкости.
- MP3-копия требует системного MP3-кодировщика Media Foundation (есть в обычных редакциях Windows 10/11;
  в редакциях N без Media Feature Pack копия сохраняется в WAV).
